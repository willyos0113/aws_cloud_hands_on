## 一、EC2 計價方案（6 題）

**1.** 公司有一批影像轉檔工作，可隨時中斷後重跑，完成時間沒有限制，希望運算成本最低。應該選哪種購買選項？

- (A) On-Demand 執行個體
- (B) Spot 執行個體
- (C) Standard Reserved Instances
- (D) Dedicated Hosts

**2.** 資料庫伺服器固定使用 m5 家族，會全年無休連續執行三年，期間不會更換機型，希望折扣最大。應該選哪種購買選項？

- (A) Convertible Reserved Instances
- (B) Spot 執行個體
- (C) Standard Reserved Instances
- (D) On-Demand 執行個體

**3.** 公司願意承諾使用一年，但未來可能把部分工作從 EC2 改到 AWS Fargate 與 AWS Lambda，希望折扣能跨這些服務套用。應該選哪一項？

- (A) Compute Savings Plans
- (B) Standard Reserved Instances
- (C) EC2 Instance Savings Plans
- (D) Spot 執行個體

**4.** 公司願意承諾使用一年，但期間可能需要換成不同的執行個體家族，並接受折扣比最深的方案略低。應該選哪一項？

- (A) Standard Reserved Instances
- (B) Spot 執行個體
- (C) On-Demand 執行個體
- (D) Convertible Reserved Instances

**5.** 公司擁有「依實體插槽與核心數計費」的既有軟體授權，需要在實體伺服器層級證明授權合規。應該選哪一項？

- (A) Dedicated Instances
- (B) Dedicated Hosts
- (C) Capacity Reservations
- (D) Spot 執行個體

**6.** 下列哪兩項是 Spot 執行個體的特性？（選兩項）

- (A) 相較 On-Demand 可享有大幅折扣
- (B) 容量被回收前，約有 2 分鐘的中斷通知
- (C) 保證在整個使用期間不會被中斷
- (D) 適合不能中斷的資料庫主節點
- (E) 必須先承諾一年的用量

## 二、Well-Architected 與 Cloud Adoption Framework（5 題）

**8.** 公司希望降低工作負載對環境的碳足跡，並提高資源使用率以減少能源消耗。這屬於 Well-Architected 的哪個支柱？

- (A) 永續性（Sustainability）
- (B) 安全性（Security）
- (C) 效能效率（Performance efficiency）
- (D) 成本最佳化（Cost optimization）

**9.** 管理層想評估組織上雲的準備度、找出人員技能與流程上的缺口，並規劃整體轉型。應該使用哪一項？

- (A) AWS Well-Architected Tool

## 三、ELB、Auto Scaling、Route 53 與 Global Accelerator（5 題）

**12.** 一個 Auto Scaling 群組已關聯到 Application Load Balancer 的 target group。當 Auto Scaling 啟動一台新的 EC2 執行個體時，會發生什麼事？

- (A) 必須由管理員手動把新執行個體註冊到 target group
- (B) ALB 會自動替 Auto Scaling 群組增加執行個體
- (C) 新執行個體會自動註冊到 target group，終止前會自動移除
- (D) 新執行個體會取代 target group 並使其刪除

**13.** 網站希望依 HTTP 路徑，把 `/api` 的請求導向 API 伺服器、`/web` 的請求導向網頁伺服器。應該使用哪一項？

- (A) Network Load Balancer
- (B) Gateway Load Balancer
- (C) Amazon Route 53
- (D) Application Load Balancer

**14.** 應用程式每秒需處理數百萬個 TCP 連線，需要極低延遲，並且要有固定的靜態 IP 位址。應該使用哪一項？

- (A) Network Load Balancer
- (B) Application Load Balancer
- (C) Amazon Route 53
- (D) Amazon CloudFront

**15.** 公司在多個 Region 部署了應用程式，希望透過 DNS 依延遲與健康狀態，把使用者導向最合適的 Region。應該使用哪一項？

- (A) Amazon CloudFront
- (B) Amazon Route 53
- (C) Amazon S3 Transfer Acceleration
- (D) Application Load Balancer

**16.** 公司需要兩組固定的 Anycast 靜態 IP 作為全球入口，讓使用者的流量從最近的邊緣位置進入 AWS 骨幹網路，再導向多個 Region 的 ALB 端點。應該使用哪一項？

- (A) Amazon Route 53
- (B) Amazon CloudFront
- (C) AWS Global Accelerator
- (D) Amazon S3 Transfer Acceleration

## 四、S3 儲存類別（5 題）

**17.** 資料的存取模式無法預測，有些物件常被存取，有些幾乎不會，公司希望自動依存取情形調整儲存層級以節省成本。應該選哪個 S3 儲存類別？

- (A) S3 One Zone-IA
- (B) S3 Intelligent-Tiering
- (C) S3 Glacier Deep Archive
- (D) S3 Standard-IA

**18.** 應用程式產生的縮圖可以隨時由原圖重新產生，很少被存取，公司願意只把資料放在單一 AZ 以換取更低的成本。應該選哪個 S3 儲存類別？

- (A) S3 Standard
- (B) S3 Glacier Flexible Retrieval
- (C) S3 Intelligent-Tiering
- (D) S3 One Zone-IA

**19.** 法規要求保存財務紀錄七年，資料幾乎不會被取回，可以接受 12 小時以上的取回時間，且要求儲存成本最低。應該選哪個 S3 儲存類別？

- (A) S3 Glacier Deep Archive
- (B) S3 Glacier Flexible Retrieval
- (C) S3 Standard-IA
- (D) S3 Glacier Instant Retrieval

**20.** 醫療影像大約每季才被存取一次，但一旦需要，必須在毫秒內取得。公司希望以封存級的成本儲存。應該選哪個 S3 儲存類別？

- (A) S3 Glacier Deep Archive
- (B) S3 Glacier Flexible Retrieval
- (C) S3 Glacier Instant Retrieval
- (D) S3 One Zone-IA

**21.** 下列哪兩項關於 Amazon S3 的敘述是正確的？（選兩項）

- (A) 使用前必須先預先配置儲存容量
- (B) 儲存總容量實質上沒有上限
- (C) 可以指定資料要存放在哪一個 AZ
- (D) S3 Standard 的資料會自動儲存在 Region 內的多個 AZ
- (E) 單一儲存貯體最多只能存放 5 GB
