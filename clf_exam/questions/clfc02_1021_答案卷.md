## 詳解

## 雲端概念、Well-Architected 與 CAF（18 題）

**1.** 答案：**A**

「隨需求自動放大、縮小」就是彈性。高可用性談的是故障時仍能運作，規模經濟談的是用量大使單價下降，兩者都不是在描述「跟著流量伸縮」。

> 出處：主教材題庫第 0139、0167 題的考點（本題為改寫，非原題）

**2.** 答案：**B**

雲端的核心財務優勢是「Trade fixed expense for variable expense」：不必預先採購硬體，用多少付多少。選項 B 剛好把方向寫反，是常見陷阱。

> 出處：主教材題庫第 0050、0133 題的考點（本題為改寫，非原題）

**3.** 答案：**CD**

「Stop guessing capacity」與「Go global in minutes」都是 AWS 官方列出的雲端優勢。其餘三項描述的是傳統地端的做法或對共同責任模型的誤解（安全是共同責任，不會全部轉移）。

> 出處：主教材題庫第 0089、0210 題的考點（本題為改寫，非原題）

**4.** 答案：**B**

元件之間透過佇列、API 等介面溝通、彼此不強依賴，就是鬆耦合；它讓各元件能獨立擴展與失敗隔離。其餘三項都與 Well-Architected 建議（自動化、小而頻繁的變更、分割工作負載）相反。

> 出處：主教材題庫第 0025、0154 題的考點（本題為改寫，非原題）

**5.** 答案：**D**

可靠性支柱的設計原則包含「自動從故障中復原」與「測試復原程序」。

> 出處：主教材題庫第 0164、0261 題的考點（本題為改寫，非原題）

**6.** 答案：**AD**

六大支柱為：營運卓越、安全性、可靠性、效能效率、成本最佳化、永續性。可用性、可擴展性是常被誤認為支柱的「特性」，並不在支柱名單內。

> 出處：主教材題庫第 0030、0268 題的考點（本題為改寫，非原題）

**7.** 答案：**D**

「Perform operations as code」、「Learn from all operational failures」都是營運卓越的設計原則。

> 出處：主教材題庫第 0093、0277 題的考點（本題為改寫，非原題）

**8.** 答案：**D**

適當配置資源（Rightsizing）與移除閒置資源，是成本最佳化支柱的核心做法。

> 出處：主教材題庫第 0102、0228 題的考點（本題為改寫，非原題）

**9.** 答案：**A**

「用對的資源做對的事」並持續檢討、實驗，是效能效率支柱的精神。

> 出處：延伸（Well-Architected 支柱）

**10.** 答案：**A**

永續性是第六個支柱，關注環境影響與資源使用效率。

> 出處：延伸（Well-Architected 支柱）

**11.** 答案：**B**

CAF 有六個視角：業務、人員、治理、平台、安全、營運。「可靠性」是 Well-Architected 的支柱，不要和 CAF 視角搞混。

> 出處：主教材題庫第 0006、0257 題的考點（本題為改寫，非原題）

**12.** 答案：**A**

雲端財務管理、效益管理、風險管理、應用程式組合管理等能力都歸在治理視角。

> 出處：主教材題庫第 0142、0344 題的考點（本題為改寫，非原題）

**13.** 答案：**A**

營運視角涵蓋可觀測性、事件管理、事件與問題管理、變更與發佈管理、效能與容量管理、組態管理與修補管理等。「事件回應（Incident response）」才是安全視角。

> 出處：主教材題庫第 0127、0137 題的考點（本題為改寫，非原題）

**14.** 答案：**CD**

平台視角包含平台架構、資料架構、資料工程、佈建與編配、現代化應用程式開發、CI/CD。事件回應屬安全、雲端熟練度屬人員、效益管理屬治理。

> 出處：主教材題庫第 0292、0101 題的考點（本題為改寫，非原題）

**15.** 答案：**D**

轉型旅程四階段：Envision（展示雲端如何加速業務成果）→ Align（找出能力差距）→ Launch（推出試辦）→ Scale（擴大規模並擴展效益）。

> 出處：主教材題庫第 0114、0145、0351 題的考點（本題為改寫，非原題）

**16.** 答案：**B**

Replatform（又稱 lift-tinker-and-shift）是為了享受雲端優勢做小幅調整，例如換成託管資料庫；Rehost 是原封不動搬移；Refactor 則是重新設計架構（例如拆成微服務）。

> 出處：主教材題庫第 0148 題的考點（本題為改寫，非原題）

**17.** 答案：**A**

同時使用地端與雲端資源並互相整合，就是混合式部署；AWS Outposts、Direct Connect 常見於此情境。

> 出處：主教材題庫第 0307 題的考點（本題為改寫，非原題）

**18.** 答案：**B**

一個 Region 由多個 AZ 組成，每個 AZ 由一個或多個資料中心構成。跨 AZ 部署是達成高可用性的基本做法。

> 出處：主教材題庫第 0022、0150 題的考點（本題為改寫，非原題）

## 共同責任模型（10 題）

**19.** 答案：**A**

RDS 是託管服務，底層作業系統與硬體由 AWS 維護；存取控制、網路規則與資料分類仍由客戶負責。

> 出處：主教材題庫第 0063、0293 題的考點（本題為改寫，非原題）

**20.** 答案：**D**

「誰能存取我的資料」永遠是客戶的責任（Security IN the cloud）。硬體、設施與服務基礎設施由 AWS 負責。

> 出處：主教材題庫第 0005、0168 題的考點（本題為改寫，非原題）

**21.** 答案：**D**

Lambda 是無伺服器服務，AWS 負責運算平台與底層作業系統；客戶負責程式碼、權限與資料。

> 出處：主教材題庫第 0042、0278 題的考點（本題為改寫，非原題）

**22.** 答案：**B**

共同控制包含修補管理、組態管理、安全意識與訓練，兩邊各自負責自己那一層。實體與虛擬化層純屬 AWS，資料與存取控制純屬客戶。

> 出處：主教材題庫第 0249、0130 題的考點（本題為改寫，非原題）

**23.** 答案：**AD**

網路存取規則、身分與權限、來賓作業系統與應用程式都由客戶負責；實體設施、硬體與虛擬化層由 AWS 負責。

> 出處：主教材題庫第 0029、0146 題的考點（本題為改寫，非原題）

**24.** 答案：**AC**

全球基礎架構與底層硬體是「Security OF the cloud」，屬 AWS；資料分類、防火牆規則、來賓 OS 修補屬客戶。

> 出處：主教材題庫第 0099、0198、0200 題的考點（本題為改寫，非原題）

**25.** 答案：**A**

IAM 政策的內容由客戶撰寫，是 Security IN the cloud，由客戶負責。

> 出處：主教材題庫第 0132、0334 題的考點（本題為改寫，非原題）

**26.** 答案：**B**

EC2 屬於 IaaS，客戶需負責來賓作業系統、修補、應用程式與網路設定；其餘三者為託管或無伺服器服務，作業系統層由 AWS 管理。

> 出處：主教材題庫第 0233、0235 題的考點（本題為改寫，非原題）

**27.** 答案：**B**

自行在 EC2 上架設資料庫，等於資料庫層全部自管；若改用 RDS，這些工作才有一部分交給 AWS。

> 出處：主教材題庫第 0008、0088 題的考點（本題為改寫，非原題）

**28.** 答案：**D**

客戶可繼承 AWS 的實體與環境控制，並可向 AWS Artifact 取得相關報告作為佐證。

> 出處：主教材題庫第 0300 題的考點（本題為改寫，非原題）

## 安全、身分、合規與監控（18 題）

**29.** 答案：**C**

root 擁有帳戶的全部權限，應啟用 MFA、不建立存取金鑰，並只在必要情況（如關閉帳戶）才使用。

> 出處：主教材題庫第 0039、0160 題的考點（本題為改寫，非原題）

**30.** 答案：**D**

AWS 服務之間的存取應使用 IAM 角色取得暫時憑證，不要在程式碼中硬編憑證。

> 出處：主教材題庫第 0004、0108、0192 題的考點（本題為改寫，非原題）

**31.** 答案：**C**

IAM Identity Center（前身為 AWS SSO）提供員工單一登入並集中管理多帳戶權限；Cognito 針對的是 App 的終端消費者。

> 出處：主教材題庫第 0170 題的考點（本題為改寫，非原題）

**32.** 答案：**C**

Cognito 專為 Web／行動應用程式的使用者驗證與授權而設計，支援社群與企業身分提供者。

> 出處：主教材題庫第 0220 題的考點（本題為改寫，非原題）

**33.** 答案：**B**

SCP 為組織內帳戶設定權限上限（guardrails），本身不授予權限，只決定能被授予的最大範圍。

> 出處：主教材題庫第 0225 題的考點（本題為改寫，非原題）

**34.** 答案：**AE**

安全群組是 stateful、只有「允許」規則、作用於 ENI／執行個體。具備子網路層級、無狀態、可明確拒絕的是網路 ACL。

> 出處：主教材題庫第 0184、0214、0289 題的考點（本題為改寫，非原題）

**35.** 答案：**A**

WAF 在第 7 層檢查 HTTP(S) 請求，可用規則（含速率限制）阻擋 SQL injection、XSS 等攻擊。

> 出處：主教材題庫第 0115、0124 題的考點（本題為改寫，非原題）

**36.** 答案：**D**

Shield Standard 自動啟用且免費；Shield Advanced 為付費的進階防護。

> 出處：主教材題庫第 0211、0223 題的考點（本題為改寫，非原題）

**37.** 答案：**A**

GuardDuty 是威脅偵測服務，透過機器學習與威脅情資分析多種日誌。Inspector 找的是弱點，Config 追蹤組態。

> 出處：延伸（安全服務）

**38.** 答案：**D**

Inspector 持續掃描 EC2、ECR 容器映像與 Lambda 函數的軟體弱點與意外網路暴露。

> 出處：主教材題庫第 0002、0117、0175 題的考點（本題為改寫，非原題）

**39.** 答案：**A**

Detective 彙整並關聯日誌資料，協助調查安全事件的根本原因。

> 出處：延伸（安全服務）

**40.** 答案：**C**

CloudHSM 提供客戶專屬的 HSM 並由客戶完全掌控金鑰；KMS 是多租戶的託管金鑰服務。

> 出處：延伸（加密服務）

**41.** 答案：**D**

Secrets Manager 可儲存密碼、API 金鑰並依排程自動輪換（例如 RDS 憑證）。

> 出處：主教材題庫第 0120、0158 題的考點（本題為改寫，非原題）

**42.** 答案：**C**

ACM 負責申請、管理與自動續約公有 SSL/TLS 憑證，並與 CloudFront、ELB 整合。

> 出處：延伸（加密服務）

**43.** 答案：**C**

Audit Manager 持續蒐集證據並產生稽核報告；Artifact 提供的是 AWS 自身的合規報告與協議，而非評估客戶的使用狀況。

> 出處：主教材題庫第 0026、0084 題的考點（本題為改寫，非原題）

**44.** 答案：**CE**

輪換金鑰與啟用 MFA 都是官方建議；共用金鑰、硬編憑證與過度授權違反最小權限與可追溯原則。

> 出處：主教材題庫第 0004、0039、0177 題的考點（本題為改寫，非原題）

**45.** 答案：**B**

AWS 滲透測試政策允許客戶對特定服務的自有資源進行測試而無須事前核准；但不得進行 DoS／DDoS 等禁止行為，實際範圍請以官方最新政策為準。

> 出處：延伸（AWS 滲透測試政策）

**46.** 答案：**C**

CloudWatch 收集指標並建立告警；CloudTrail 記錄的是 API 呼叫（誰做了什麼），Config 記錄資源組態變更。

> 出處：主教材題庫第 0111、0314 題的考點（本題為改寫，非原題）

## 運算、容器、無伺服器與開發工具（15 題）

**47.** 答案：**C**

事件驅動、短時間執行、無須管理伺服器的工作適合 Lambda，並依請求次數與執行時間計費。

> 出處：主教材題庫第 0118、0278 題的考點（本題為改寫，非原題）

**48.** 答案：**A**

EKS 是託管的 Kubernetes 服務；ECS 是 AWS 自家的容器編排服務，並非 Kubernetes。

> 出處：主教材題庫第 0121 題的考點（本題為改寫，非原題）

**49.** 答案：**D**

Amazon Elastic Container Registry（ECR）用於儲存、管理與部署容器映像，並與 ECS、EKS 整合。

> 出處：延伸（容器服務）

**50.** 答案：**C**

Lightsail 提供預先設定的應用程式堆疊、固定價格，適合小型網站、部落格與簡單應用。

> 出處：主教材題庫第 0329 題的考點（本題為改寫，非原題）

**51.** 答案：**A**

Step Functions 以狀態機編排工作流程；SQS 只負責訊息佇列，不負責流程控制。

> 出處：主教材題庫第 0140 題的考點（本題為改寫，非原題）

**52.** 答案：**A**

Dedicated Hosts 提供實體伺服器的可見度與控制，可沿用依 socket／core 計價的既有授權；Dedicated Instances 則沒有這種主機層級的可見度。

> 出處：延伸（EC2 採購選項）

**53.** 答案：**A**

Compute Savings Plans 最有彈性，可跨 EC2（不限家族與 Region）、Fargate、Lambda 套用；EC2 Instance Savings Plans 則限定特定執行個體家族。

> 出處：主教材題庫第 0138、0267 題的考點（本題為改寫，非原題）

**54.** 答案：**B**

Spot 中斷前約有 2 分鐘的警告時間，應用程式需能容忍中斷並儲存進度。

> 出處：主教材題庫第 0136、0213 題的考點（本題為改寫，非原題）

**55.** 答案：**BE**

Spot 價格最低但可能被回收，只適合可中斷、無狀態、具彈性的工作負載。

> 出處：主教材題庫第 0057、0067、0250 題的考點（本題為改寫，非原題）

**56.** 答案：**D**

ALB 運作於第 7 層，支援路徑式與主機式路由；NLB 在第 4 層處理 TCP/UDP。

> 出處：延伸（Elastic Load Balancing）

**57.** 答案：**B**

Systems Manager 提供 Patch Manager、Run Command、Session Manager 等功能，可免開 SSH 管理大量執行個體。

> 出處：主教材題庫第 0346 題的考點（本題為改寫，非原題）

**58.** 答案：**D**

CodePipeline 負責編排整條 CI/CD 流程，可串接 CodeBuild（建置）與 CodeDeploy（部署）。

> 出處：主教材題庫第 0306 題的考點（本題為改寫，非原題）

**59.** 答案：**A**

API Gateway 用來建立、發佈、保護與監控 API，常與 Lambda 組成無伺服器後端。

> 出處：延伸（無伺服器架構）

**60.** 答案：**D**

EventBridge 可依排程或事件規則觸發目標（如 Lambda），是事件驅動架構的核心。

> 出處：延伸（事件驅動架構）

**61.** 答案：**C**

SNS 是發佈／訂閱（pub/sub）服務，一則訊息可扇出（fan-out）給多個訂閱者；SQS 是佇列，一則訊息通常由一個消費者處理。

> 出處：主教材題庫第 0031、0081、0188 題的考點（本題為改寫，非原題）

## 儲存、資料庫、分析與遷移（15 題）

**62.** 答案：**D**

Deep Archive 是成本最低的 S3 儲存類別，適合長期封存且很少取回的資料。

> 出處：主教材題庫第 0251、0274 題的考點（本題為改寫，非原題）

**63.** 答案：**B**

Intelligent-Tiering 會依存取模式自動在不同層級間移動物件。

> 出處：主教材題庫第 0251 題的考點（本題為改寫，非原題）

**64.** 答案：**D**

版本控制會保留物件的多個版本，可用來復原誤刪或誤覆寫。

> 出處：延伸（S3 功能）

**65.** 答案：**AD**

Lifecycle 與適當的儲存類別是降低 S3 成本的主要手段；Transfer Acceleration 是加速傳輸（會另外收費），永久保留舊版本反而增加儲存量。

> 出處：主教材題庫第 0251、0274 題的考點（本題為改寫，非原題）

**66.** 答案：**A**

EFS 是可被多台執行個體同時掛載的託管檔案系統；EBS 一般一次只掛載到一台執行個體。

> 出處：延伸（儲存服務）

**67.** 答案：**D**

Instance store 位於主機本機磁碟，適合暫存資料；需要持久保存的資料應使用 EBS、EFS 或 S3。

> 出處：延伸（儲存服務）

**68.** 答案：**A**

AWS Backup 是集中式備份服務，可跨多種 AWS 服務套用備份計畫與保留政策。

> 出處：主教材題庫第 0068 題的考點（本題為改寫，非原題）

**69.** 答案：**C**

讀取複本可分擔讀取流量以提升效能；Multi-AZ 的目的則是高可用性與容錯移轉，兩者目的不同。

> 出處：主教材題庫第 0161 題的考點（本題為改寫，非原題）

**70.** 答案：**C**

Aurora 是 AWS 自行設計的雲端關聯式資料庫，相容 MySQL／PostgreSQL，儲存跨 3 個 AZ 保存 6 份副本並自動擴展。

> 出處：主教材題庫第 0055、0161 題的考點（本題為改寫，非原題）

**71.** 答案：**D**

ElastiCache（Redis／Memcached）是記憶體內快取服務，可降低資料庫讀取壓力。

> 出處：延伸（資料庫與快取）

**72.** 答案：**B**

Kinesis Data Streams 專為即時、大規模串流資料的擷取與處理而設計。

> 出處：延伸（資料分析）

**73.** 答案：**C**

OpenSearch Service 適用於全文檢索、日誌分析與即時應用監控；Neptune 是圖形資料庫，Timestream 是時間序列資料庫。

> 出處：主教材題庫第 0248、0308 題的考點（本題為改寫，非原題）

**74.** 答案：**AD**

SCT 負責轉換結構描述與程式碼，DMS 負責搬移資料並支援持續複寫。

> 出處：主教材題庫第 0227、0316 題的考點（本題為改寫，非原題）

**75.** 答案：**C**

Snowball Edge 可在無網路或弱網路環境下就地儲存與處理資料，再寄回 AWS 匯入。

> 出處：主教材題庫第 0191、0270、0276 題的考點（本題為改寫，非原題）

**76.** 答案：**D**

Transfer Family 提供託管的 SFTP、FTPS、FTP 端點，後端直接對應 S3 或 EFS。

> 出處：主教材題庫第 0123 題的考點（本題為改寫，非原題）

## AI／ML 服務（4 題）

**77.** 答案：**C**

Rekognition 負責影像與影片分析；Comprehend 是文字分析，Polly 是文字轉語音，Transcribe 是語音轉文字。

## 網路、混合雲與全球基礎架構（8 題）

**81.** 答案：**B**

CloudFront 透過遍布全球的邊緣位置快取內容以降低延遲；Global Accelerator 同樣使用邊緣位置。

> 出處：主教材題庫第 0049、0194、0321 題的考點（本題為改寫，非原題）

**82.** 答案：**B**

Failover 搭配健康檢查，主要資源不健康時自動切換到備援資源。

> 出處：主教材題庫第 0080、0208、0242 題的考點（本題為改寫，非原題）

**83.** 答案：**A**

S3 與 DynamoDB 支援 Gateway endpoint，流量留在 AWS 網路內，不需 NAT 或 IGW。

> 出處：延伸（VPC 網路）

**84.** 答案：**B**

NAT gateway 讓私有子網路主動對外連線，同時阻擋由外向內的連線；NAT gateway 本身依小時與流量計費，要留意成本。

> 出處：延伸（VPC 網路）

**85.** 答案：**CD**

Direct Connect 是專用實體線路，Site-to-Site VPN 是經網際網路的加密 IPsec 通道，兩者可獨立使用或搭配備援。

> 出處：主教材題庫第 0021、0073、0326 題的考點（本題為改寫，非原題）

**86.** 答案：**B**

Wavelength 將 AWS 運算與儲存嵌入電信業者的 5G 網路，讓行動裝置流量不必離開電信網路即可存取。

> 出處：延伸（全球基礎架構）

**87.** 答案：**A**

子網路是否為公共，取決於路由表是否有通往 IGW 的路由（資源通常還需要公有 IP），與名稱無關。

> 出處：主教材題庫第 0024 題的考點（本題為改寫，非原題）

**88.** 答案：**D**

NLB 運作於第 4 層，可處理每秒數百萬請求並提供每個 AZ 的靜態 IP。

> 出處：延伸（Elastic Load Balancing）
