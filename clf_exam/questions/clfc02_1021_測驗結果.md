## 詳解

## 雲端概念、Well-Architected 與 CAF（18 題）

**10.** 答案：**A**

永續性是第六個支柱，關注環境影響與資源使用效率。

👉 WA 的永續支柱 -> 資源使用效率、節能。

> 出處：延伸（Well-Architected 支柱）

**12.** 答案：**A**

雲端財務管理、效益管理、風險管理、應用程式組合管理等能力都歸在治理視角。

👉 CAF 中的治理視角 -> 財務、效益、風險、應用組合。

> 出處：主教材題庫第 0142、0344 題的考點（本題為改寫，非原題）

**13.** 答案：**A**

營運視角涵蓋可觀測性、事件管理、事件與問題管理、變更與發佈管理、效能與容量管理、組態管理與修補管理等。「事件回應（Incident response）」才是安全視角。

👉 CAF 中的營運視角 -> 觀測、事件處理回應、變更發布、效能容量等等。

> 出處：主教材題庫第 0127、0137 題的考點（本題為改寫，非原題）

**14.** 答案：**CD**

平台視角包含平台架構、資料架構、資料工程、佈建與編配、現代化應用程式開發、CI/CD。事件回應屬安全、雲端熟練度屬人員、效益管理屬治理。

👉 CAF 中的平台視角 -> 包含CICD、資料工程、config、develop 相關。

> 出處：主教材題庫第 0292、0101 題的考點（本題為改寫，非原題）

**16.** 答案：**B**

Replatform（又稱 lift-tinker-and-shift）是為了享受雲端優勢做小幅調整，例如換成託管資料庫；Rehost 是原封不動搬移；Refactor 則是重新設計架構（例如拆成微服務）。

👉 選 replatform，因從自建 DB 改為託管式雲端 DB。

> 出處：主教材題庫第 0148 題的考點（本題為改寫，非原題）

## 安全、身分、合規與監控（18 題）

SCP 為組織內帳戶設定權限上限（guardrails），本身不授予權限，只決定能被授予的最大範圍。

👉 SCP -> 設定帳戶服務權限上限。

> 出處：主教材題庫第 0225 題的考點（本題為改寫，非原題）

**39.** 答案：**A**

Detective 彙整並關聯日誌資料，協助調查安全事件的根本原因。

👉 detective -> 調查事件根因。

> 出處：延伸（安全服務）

**40.** 答案：**C**

CloudHSM 提供客戶專屬的 HSM 並由客戶完全掌控金鑰；KMS 是多租戶的託管金鑰服務。

👉 HSM -> 由客戶完全保管金鑰。

> 出處：延伸（加密服務）

## 運算、容器、無伺服器與開發工具（15 題）

**48.** 答案：**A**

EKS 是託管的 Kubernetes 服務；ECS 是 AWS 自家的容器編排服務，並非 Kubernetes。

👉 EKS -> AWS 的 kubernetes。

> 出處：主教材題庫第 0121 題的考點（本題為改寫，非原題）

**50.** 答案：**C**

Lightsail 提供預先設定的應用程式堆疊、固定價格，適合小型網站、部落格與簡單應用。

👉 預先設定 stack、價格等 -> Lightsail(幫你包好好的簡易 ec2)。

> 出處：主教材題庫第 0329 題的考點（本題為改寫，非原題）

**51.** 答案：**A**

Step Functions 以狀態機編排工作流程；SQS 只負責訊息佇列，不負責流程控制。

👉 管理多個 lambda 函數服務(也可以是多個 ec2 或多個 ecs)的工作流程 -> step functions。

> 出處：主教材題庫第 0140 題的考點（本題為改寫，非原題）

**53.** 答案：**A**

Compute Savings Plans 最有彈性，可跨 EC2（不限家族與 Region）、Fargate、Lambda 套用；EC2 Instance Savings Plans 則限定特定執行個體家族。

👉 1年、且折扣需跨 EC2、Fargate、Lambda -> compute savings plans。

> 出處：主教材題庫第 0138、0267 題的考點（本題為改寫，非原題）

**54.** 答案：**B**

Spot 中斷前約有 2 分鐘的警告時間，應用程式需能容忍中斷並儲存進度。

👉 收回前會有 2 分鐘的警告。

> 出處：主教材題庫第 0136、0213 題的考點（本題為改寫，非原題）

**57.** 答案：**B**

Systems Manager 提供 Patch Manager、Run Command、Session Manager 等功能，可免開 SSH 管理大量執行個體。

👉 提供 Patch、run command、session manager 等功能 -> system manager(用來如 SSM 綁定 INSTANCE)。

> 出處：主教材題庫第 0346 題的考點（本題為改寫，非原題）

## 儲存、資料庫、分析與遷移（15 題）

**62.** 答案：**D**

Deep Archive 是成本最低的 S3 儲存類別，適合長期封存且很少取回的資料。

👉 (1) Glacier Deep Archive -> 12hr 以上、(2) Glacier Flexible (5min ~ 12hr)。

> 出處：主教材題庫第 0251、0274 題的考點（本題為改寫，非原題）

**68.** 答案：**A**

AWS Backup 是集中式備份服務，可跨多種 AWS 服務套用備份計畫與保留政策。

👉 AWS backup。

> 出處：主教材題庫第 0068 題的考點（本題為改寫，非原題）

**69.** 答案：**C**

讀取複本可分擔讀取流量以提升效能；Multi-AZ 的目的則是高可用性與容錯移轉，兩者目的不同。

👉 RDS 的 Replica 功能就是拿來分攤讀取流量的。

> 出處：主教材題庫第 0161 題的考點（本題為改寫，非原題）

**73.** 答案：**C**

OpenSearch Service 適用於全文檢索、日誌分析與即時應用監控；Neptune 是圖形資料庫，Timestream 是時間序列資料庫。

👉 OpenSearch -> 全文檢索。

> 出處：主教材題庫第 0248、0308 題的考點（本題為改寫，非原題）

**74.** 答案：**AD**

SCT 負責轉換結構描述與程式碼，DMS 負責搬移資料並支援持續複寫。

👉 SCT -> 轉換程式碼、DMS -> 搬資料和複寫。

**75.** 答案：**C**

Snowball Edge 可在無網路或弱網路環境下就地儲存與處理資料，再寄回 AWS 匯入。

## AI／ML 服務（4 題）

**78.** 答案：**C**

Transcribe 將語音轉成文字；Polly 方向相反（文字轉語音）。

👉 Polly 是文字轉語音；Transcribe 才是逐字稿。

> 出處：主教材題庫第 0328 題的考點（本題為改寫，非原題）

**92.** 答案：**C**

Business 起提供 24x7 電話／聊天／電子郵件與完整的 Trusted Advisor 檢查；Developer 僅營業時間以電子郵件聯絡。

👉 Business support 開始就有 7x24、聊天、email 聯絡和 Trusted Advisor。

> 出處：主教材題庫第 0071、0135 題的考點（本題為改寫，非原題）

**93.** 答案：**B**

Developer 適合測試與開發環境，僅提供營業時間的電子郵件支援；TAM 與 Concierge 屬 Enterprise 等級。

👉 Developer support 只有營業時間的 email 聯絡方式。

> 出處：主教材題庫第 0236 題的考點（本題為改寫，非原題）

**94.** 答案：**C**

指定 TAM、Concierge 與基礎架構事件管理（IEM）是 Enterprise 等級的特色。

👉 Enterprise support 特色包含 TAM 專屬技術、最佳化工作負載。

> 出處：主教材題庫第 0071、0135、0236、0246 題的考點（本題為改寫，非原題）

**95.** 答案：**A**

Convertible RI 允許在期限內換成不同屬性的 RI（折扣較 Standard 略低但更彈性）。

👉 Convertible RI 可以換機器。

> 出處：主教材題庫第 0136、0138 題的考點（本題為改寫，非原題）

**96.** 答案：**C**

進入 AWS 的流量與同 Region 內 S3→EC2 的傳輸免費；出站到網際網路、跨 Region 與跨 AZ 傳輸通常會收費。

👉 不會產生費用的流量，(1) Internet 進入 AWS (2) 同 Region 內的 S3 到 EC2。
